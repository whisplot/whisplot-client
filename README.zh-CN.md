# Whisplot

<img src="apps/mobile/assets/branding/app_logo.png" width="96" alt="Whisplot app icon" />

一个适合 10～50 人小群的聊天 App。用邀请码入群，不需要手机号或邮箱；显示 ID 自动更换，所有人的消息都在中间。爱咋聊，就咋聊。

## 0.1.0 Build 18

[下载 Whisplot 0.1.0](https://github.com/whisplot/whisplot-client/releases/tag/v0.1.0)，适用于 Android、macOS 和 Windows。0.1.0 默认连接新的 Whisplot 服务。可以新建群聊，或使用新服务的邀请码入群。旧服务的群聊和消息留在原服务。

## 语言

Whisplot 首次打开默认英文。点击首页或设置中的 **中文 / EN** 即时切换，重启后保留选择；聊天正文和群名保持原文。

## 打开与入群

App 自动创建设备身份并连接内置服务，不需要填写手机号、邮箱、账号密码或真实姓名。覆盖安装时会把旧官方服务地址切换到新地址。

- **创建群：**点击**创建群聊**并输入名称，进入聊天后点邀请按钮，再点**复制邀请码**，私下发给朋友。
- **加入群：**点击**邀请码入群**，粘贴 **22 位短码**，再点**验证并加入**。请与邀请人连接同一个服务。仍然有效的旧版完整邀请链接也可以使用。
- **重新连接：**换 Wi-Fi 或恢复网络后会自动重试；需要时点**重新连接**或聊天中的连接横幅。

短码需要联网领取；到期、撤销、次数用完或群换密钥后会失效。每群最多 50 个设备身份，无法加入时请群主重新邀请。

新加入或重新加入群，只补收这次**入群前 24 小时**及之后的消息，不会自动擦除已经保存在本机的记录。实际可补收范围也取决于服务保留期和本机持有的群密钥。

## 发消息与回应

输入文字后点击发送箭头。Mac 上 **Enter 发送，Shift + Enter 换行**。气泡居中，文字正常排版，不显示头像，也不区分自己或他人发言的左右位置。顶部以群名为主，下面显示当前 ID 和在线总人数。

- **复制：**点击文字消息下面的小复制图标。
- **引用：**把文字或语音消息左滑后松手，输入框上方出现引用，可点 × 取消。点击已发消息或输入框中的引用，就会定位到当前群的本机原消息；原消息不在本机时显示占位提示。
- **点赞：**双击气泡，包括其中的引用，添加 **♥️**；重复双击保持点赞。点击自己已添加的爱心可取消。
- **选择回应：**长按消息，上方是最近表情，下方是完整表情库；支持分类和中英文搜索。所有回应都用同一种橙色背景，带短动画，并遵循减少动态效果设置。
- **在文字里输入表情：**点输入框旁的表情按钮，在光标处插入，不会自动发送。**3,944 个表情**随 App 内置，浏览不用额外下载或连接 CDN。

发文字、引用或语音后会滑到最新消息底部，超长消息也能看到末尾。手动翻历史或查看旧引用时，别人的新消息不会把页面拉走。

在**设置 → 每几条消息换 ID**中选择 **1、10 或 50 条**，默认一条一换。文字和语音进入发送队列就计数，离线也一样；表情回应不计数，没有手动改名按钮。自己的旧消息显示**已过期 ID**，群和记录保留。其他成员的副本及底层设备身份没有被擦除，因此不同 ID 的活动仍可能被关联。

## 语音、外观与屏幕隐私

点麦克风，允许权限后最多录制 **30 秒**。停止后先试听变声效果，再确认发送。变声在本机完成，只发送处理后的录音；离开录音面板或切换 App 会取消未完成的录音。变声会保留部分声音特征，**不能保证匿名**。播放时可能生成临时明文音频，正常结束和后续启动清理会删除它。

在**设置 → 外观**选择**米白**或**纯黑**。Android 使用安全窗口限制常规截图、录屏和最近任务预览。Mac 切换到其他 App 时遮住聊天内容，返回 Whisplot 后恢复。QQ 可以同时开着；Whisplot 不再检查 QQ 是否运行。

Mac 遮罩用于隐藏切到后台后的内容，不能阻止录制前台可见的 Whisplot。屏幕保护和 ID 轮换都不代表绝对匿名。

## 已发送、已读取、在线与提醒

**等待发送**表示消息还在本机队列中；**已发送**表示服务已经接收或点对点成员已经收到。发送者之外至少一名成员看到消息并发回有效回执后，收到回执的所有成员都会看到**已读取**。下载到设备不算阅读。

在线人数包含自己，只显示总数。停留首页、其他群或切到后台，只要连接仍在就可以保持在线，并不代表正在看消息。心跳停止后可能约 **90 秒**才从人数中消失；无法确认时显示“在线 —”。

在 Android、macOS 或 Windows 的**设置 → 消息提醒**开启提醒。若系统已阻止通知，点**打开系统通知设置**，允许后返回 Whisplot。提醒只显示有新消息，点击后 Android 和 macOS 打开对应群，Windows 恢复 Whisplot 窗口。

Mac 切换 App 或点红色关闭按钮后仍在后台运行，点 Dock 图标恢复窗口。**Command + Q** 或**退出Whisplot**才完全退出。

Android 使用常驻的**“正在保持后台连接”**通知支持当前连接，切换 App 或锁屏不会主动断开。划掉 App、强制停止、系统休眠或厂商冻结仍可能中断收信，重新打开后补收。运行中的连接不依赖 Google Play 服务，当前未配置 App 完全退出后的远程推送。物理锁屏行为不宣称已经在所有设备完成验收。

## 退出或删除聊天空间

**保留历史：**打开聊天菜单，选**退出群聊**并确认。任何成员都能退出，包括群主。此群停止收发，已保存消息留在首页的**已退出的群 · 本机历史**中。

**同时删除本机历史：**首页把聊天空间左滑，点**删除**，再确认**退出并删除**。Mac 也可用触控板横向滑动或右键打开相同操作；已退出的空间也能删除。取消确认会保留空间和记录，确认删除后无法在 App 中恢复。

离线操作显示**退群待确认**，联网后由服务确认。群主退出会交接给剩余成员，最后一人退出则关闭群。剩余群暂时停止发新消息，等待群主更新密钥；让已升级的群主保持在线，或点**更新原群密钥**重试。

更新原群密钥保留原群和历史，让旧邀请码失效，并用新密钥隔离后续讨论。旧消息及其他设备已持有的副本不能撤回。已签发的离线点对点票据最长可有效至签发后 15 分钟。

## 常见问题

**连接或发送卡住：**检查网络，点**重新连接**。先处理必须更新或参与验证提示；离线参与验证最长 15 分钟，需要联网续期。旧密钥待发消息会保留供查看，不会自动转成新密钥重发。不要通过卸载来排查问题。

**原来的群提示缺少密钥：**每台设备更新到最新版，群主在原群菜单点**更新本群密钥**。已升级成员仍缺密钥时，群主可点**为已升级成员补发密钥**，随后重新连接，无需另建群。

**提示服务今日额度已用完：**待发送消息仍保存在本机。App 最多等待 15 分钟就重新检查，也可以点**重新连接**提前检查；能否恢复仍取决于服务是否已经可用。

**Mac 询问钥匙串：**只在系统弹窗中批准可信 App。本机加密密钥库减少迁移后的重复读取，但首次迁移或签名变化仍可能要求授权。拒绝访问会暂停初始化并保留原身份；保留应用数据和钥匙串项目，处理后重试。旧版 Mac 客户端无法打开迁移后的数据库。

**换设备：**每次安装都有独立身份，用邀请码在另一台设备入群。当前没有账号找回或设备历史迁移流程；卸载或清数据可能丢失群访问权和本机记录。

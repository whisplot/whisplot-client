# Whisplot 客户端补充指南

日常操作见 [中文使用说明](../README.zh-CN.md) 或 [English user manual](../README.md)。本文件补充使用边界和客户端开发方法，不包含服务端源码或部署资料。

本文适用于 Whisplot 0.1.0。三个平台的安装包及校验值见 [Whisplot 下载页](https://whisplot-downloads.pages.dev/)。

## 连接、身份与升级

Android、macOS 和 Windows 发布包打开后会自动连接 Whisplot 服务。加入已有群需要有效邀请码。每台设备使用自己的身份，服务方和群成员仍可能关联临时 ID 前后的活动。

默认服务自动选择可达入口，优先直连；换网后尝试重连。入口变化不修改已保存的服务地址、身份、群或记录。自定义服务继续使用自己的配置，不会自动切换到默认服务。连通性仍取决于当前网络和服务状态；不要跳过证书检查。

请在原 App 上覆盖安装，保留本机数据和钥匙串。新服务上的群聊仍可使用。连接到旧服务的群聊记录可在本机查看，在新服务中入群需要新服务的邀请码。

群主可从聊天菜单选择**更新本群密钥**，原群和成员保留，新消息使用新密钥，旧邀请码失效。其他成员先升级并联网，再由群主在线分发新密钥；必要时选择**为已升级成员补发密钥**后重新连接。历史模式不能恢复发送、邀请或点对点通信。

旧密钥继续用于读取本机历史。标为**旧密钥待发 · 未自动重发**的消息不会自动重新加密并发到新版本，请查看内容后自行决定是否重新发送。

## 退群、删除与入群历史

每个人都能从聊天菜单选择**退出群聊**，包括群主和只读群成员。确认后停止该群收发，未发送的内容不再发出；本机历史保存在首页折叠的**已退出的群 · 本机历史**，仍可阅读、复制。

首页聊天空间向左滑动会露出**删除**按钮。选择后再次确认**退出并删除**，才会退群并清除该群的本机记录；取消不会退出或清除。已退出的群也能左滑后确认**删除记录**。Mac 横向触控板滚动和右键同样可以显示删除操作。清除仅针对所选群和当前设备，不能删除其他成员的副本，也不能在 App 内撤销。

新加入或重新加入时，只同步本次入群前 **24 小时**及入群后的消息；时间下界以入群时间为基准，不会随着时间推移自动擦除已有本机记录。它不保证读取所有符合时间范围的消息，实际还受服务保留期和可用群密钥限制。离线后回来补收本次入群以来的消息也继续受这些条件约束。

离线时先停止本机收发，显示**退群待确认**，联网后自动尝试确认。群主退出后自动交接给剩余成员，最后一人退出则关闭群聊。服务确认后，剩余成员暂停新发送，等待群主更新密钥；群主保持升级后的 App 在线即可自动尝试，也可手动重试。更新完成后以新密钥继续原群讨论，已退出成员不会获得新密钥。

已经签发的离线点对点票据最长可有效至签发后 **15 分钟**。离线旧连接无法瞬时撤销，已收到的旧消息与旧密钥也不能远程收回。新密钥用于隔离后续讨论，不能让别人忘掉历史。参与票据验证不等于证明对方运行的是未经修改的官方 App，也不保证绝对匿名。

## 表情与文字

长按消息直接打开完整的 **3,944 个静态 Twemoji 表情**。最近选择在上方，全库在下方；没有“更多”按钮，可通过分类图标和中英文搜索选择。最多保存 **24 个本机最近表情**，只保存表情和顺序，不记录时间、群、成员或搜索词，也不通过钥匙串保存这项偏好。

输入框旁的表情按钮打开相同面板，把所选表情插入光标位置或替换选区。可以与文字混合，选完不会自动发送。对消息的回应每人每条保留一个，重选可取消、选择另一个则替换。Twemoji 图片与目录随 App 内置，无需表情 CDN；许可见**设置 → 表情资源与开源许可**。

所有人的消息气泡居中，临时 ID 位于正文上方，没有头像或左右区分。正文两端对齐，复制图标在气泡下方，回应和数量在气泡内。build 9 本地修订版的回应背景统一为爱马仕橙，不再通过颜色、选中提示或辅助功能状态标记自己的回应。新增回应伴随一次短动画，结束后静止；历史加载不重播，系统开启减少动态效果时直接显示结果。

临时 ID 默认每发 **1 条**自动更换，设置提供 **1、10、50** 三档。文字和语音进入待发送队列即计数，回应不计数；更改档位或重启不清零。自己的旧 ID 在本机显示“已过期 ID”，不能保证从签名消息、数据库、备份或他人副本中不可恢复。

引用预览可以点击：平滑滚动到本群已保存在本机的原消息，并短暂高亮。没有原消息时显示占位提示，不会跳到其他群。聊天顶栏以群名为主标题，ID 在下方；连接详情从连接横幅打开。

## 离线、语音与隐私边界

当前参与验证和群密钥仍有效时，内容可进入本机待发送队列。验证最长 **15 分钟**，过期后暂停发送和点对点通信，联网验证后恢复。换网会自动尝试重连。服务已接收或通过点对点收到的消息显示“已发送”；发送者之外再有一位成员看到并返回有效回执后，所有收到回执的成员都显示“已读取”。尚未确认送出的消息显示“等待发送”。离线消息和语音的恢复范围受服务保留规则限制，不能视为永久备份。

语音最多 **30 秒**，在本机变声、试听后确认发送，不下载模型或云端转写。原声用于内存处理，只发送变声录音；保留语气也会保留部分可识别特征。待发送附件和缓存加密，播放时会产生临时明文 WAV，结束、取消或下次启动清理。变声不能保证隐藏声纹。切换 App 或关闭录音面板会取消未完成录音。

外观可选米白或纯黑。Android 用安全窗口限制常规截图、录屏和任务预览；Mac 失焦遮罩不能可靠阻止前台截图或第三方录屏，也不能阻止相机拍摄。当前没有完成独立安全审计，不提供前向保密或绝对匿名保证。

完整邀请码应私下分享。短码不省略邀请秘密或群密钥；撤销邀请码不能撤回已分享的内容。build 9 新成员只同步其入群前 24 小时及之后、且拥有相应群密钥的可用消息；这不能收回已经分发的旧消息或阻止其他成员主动转发旧内容。build 9 提供自行退群和本机记录删除；当前没有群主主动移除指定成员的操作。管理员和服务方仍能看到必要的群、设备及连接元数据。

## 安装与通知限制

安装方法见 [Mac 使用说明](macos.md)及 README。Mac 包使用固定的本地自签证书和保持不变的沙盒密钥组件，没有 Apple Developer ID 签名，也未经过 Apple 公证。无需导入签名证书；首次启动可能需要在系统设置中批准这个 App。首次迁移旧密钥或系统权限变化仍可能请求钥匙串授权；拒绝时停止初始化，不覆盖原身份。请保留数据，不要清空钥匙串绕过问题。

Mac 密钥库使用 AES-256-GCM 加密身份和群密钥，以事务保存到本机数据库；随机主密钥单独保存在钥匙串，成功解锁后在当前运行内复用，切群和密钥写入不再请求系统授权。首次迁移旧项目可能逐项请求授权，每项成功后保存加密进度，取消后需手动点**重新尝试**。旧钥匙串项目保留，完成后不再读取；密文、主密钥缺失或完整性校验失败会停止初始化，不会生成替代身份。Mac 数据库升级后拒绝旧客户端打开，Android 数据库与存储方式保持原状。固定组件减少主程序更新后的重复授权，但组件换版、钥匙串锁定或系统权限变化仍可能再次询问。

Mac 提供运行中的系统消息提醒、声音与 Dock 未读角标；红叉隐藏窗口继续收信，Dock 或通知点击恢复，Command+Q 完全退出后停止。Android 使用前台服务和不含聊天内容的常驻通知维持现有进程；切到后台或锁屏后不主动断网，网络与进程继续运行时可接收消息提醒。系统 Doze 或厂商限制仍可能暂停网络，划掉任务或强制停止会结束服务；完全退出后的远程推送尚未配置。详见 [消息提醒](notifications.md)。

卸载、清除数据或换设备可能失去身份、群资格和本机记录。Android、Mac 和 Windows 各自保存本机身份和聊天记录。

自动化测试不能代替手机真机、Intel Mac、真实麦克风、第三方屏幕捕获或 50 台跨设备验收。本版验证范围见发布说明；旧版通过的项目不能直接算作本版通过。

## 客户端开发补充

公开仓库仅包含客户端。运行它需要管理员提供可用的测试服务；这里不提供服务端部署操作或私有源码。

0.4.0 的表情扩展格式、旧版隐藏行为及真实旧源码兼容测试，见 [Reaction protocol compatibility](reaction-protocol.md)。日常使用不需要了解该格式。

工具链：Flutter 3.50.0 / Dart 3.14.0。Android 需要 Android SDK 和 JDK 21；Mac 和 iOS 需要 macOS、Xcode 及对应构建组件，iPhone 安装还需要有效 Apple 签名。使用仓库锁定的依赖版本。

在仓库根目录执行：

```sh
cd apps/mobile
../../scripts/flutter.sh pub get
../../scripts/flutter.sh analyze
../../scripts/flutter.sh test
../../scripts/flutter.sh run
```

官方发布包已内置默认连接配置。从源码自行运行时，使用 `--dart-define=WHISPLOT_SHOW_CONNECTION_SETTINGS=true` 可显示测试服务设置。若要自动连接，用仓库外的私有 JSON 文件配置 `DEFAULT_API_BASE_URL` 和 `DEFAULT_REGISTRATION_CODE`，再将该文件的绝对路径传给 `--dart-define-from-file`。

只向客户端构建注入默认服务地址及 App 接入码。管理员令牌、长期中继凭证、签名私钥和推送服务密钥不属于客户端构建配置。

Android ARM64 构建：

```sh
../../scripts/flutter.sh build apk --release --target-platform android-arm64 --split-per-abi
```

需要内置默认配置的发布构建，在该命令后追加 `--dart-define-from-file=/absolute/path/private-config.json`。路径应指向自己的私有文件。

当前 release 构建仍采用测试签名，release 只代表优化模式。长期分发前应配置并备份自己的签名密钥，保证后续兼容更新。

Mac 本地运行与构建：

```sh
../../scripts/flutter.sh run -d macos
../../scripts/flutter.sh build macos --release
```

Mac 的发布构建同样可追加 `--dart-define-from-file=/absolute/path/private-config.json`。自动连接配置只补充缺少的默认设置，不应覆盖已保存的自定义服务或生成新身份替代旧身份。

生成用于分发的 APK 或 Mac ZIP 时，也可以在 `apps/mobile` 目录使用打包脚本。通过环境变量提供同一个私有配置文件，文件中只放上述两个默认连接字段：

```sh
HELLO_MENTOR_DART_DEFINE_FILE=/absolute/path/private-config.json ../../scripts/package-android.sh
HELLO_MENTOR_DART_DEFINE_FILE=/absolute/path/private-config.json ../../scripts/package-macos.sh
```

脚本把产物放到仓库的 `artifacts/`，不会打印接入码。需要验证 Android 覆盖更新时，可用 `HELLO_MENTOR_PREVIOUS_ANDROID_APK` 指向上一个发布 APK，检查签名一致和版本递增。私有配置文件不随源码或发布附件上传。

普通 release 构建不等于 Developer ID 签名、公证或成功分发。开发时不要把机器上其他项目的签名身份默认用于本项目；产物架构和最低系统版本应以实际包的检查结果为准。有关 Flutter 的 Xcode 项目和构建设置，见 [官方 macOS 构建文档](https://docs.flutter.dev/deployment/macos)。本轮按本地构建流程推进，不依赖 GitHub Actions。

iPhoneOS 未签名构建：

```sh
../../scripts/flutter.sh build ios --release --no-codesign
```

这条命令不会产生能直接安装到 iPhone 的已签名应用。当前客户端不包含推送平台配置，普通单元及界面测试通过也不代表真实推送、跨网络连接或 iPhone 运行已经验收。

客户端测试需要仓库 `fixtures/` 中的固定公开测试数据，不能把这些数据用于真实身份。源码中的既有包名和应用标识继续保留，产品显示名为Whisplot。
